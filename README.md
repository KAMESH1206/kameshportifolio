# Kamesh M R — Application Developer Portfolio

A responsive Next.js 15 + React + TypeScript portfolio using Framer Motion and Lucide icons. Design direction: premium white, black and electric blue with a CSS-built 3D-style developer avatar.

## Run locally

1. Install Node.js 20 or newer.
2. Extract this folder and open it in VS Code.
3. In the project folder, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open http://localhost:3000.

## Before publishing

Update these placeholders in `app/page.tsx`:
- `kameshmr@example.com` with your actual professional email.
- GitHub and LinkedIn profile URLs in the footer.
- Project links and replace illustrative project mockups with approved screenshots.
- Confirm education dates, project descriptions and experience details.

The GoJobSync project link currently points to `https://gojobs.io`. SmartVote AI and Vendora links are placeholders until you provide their public demo/repository URLs.

## Build for production

```bash
npm run build
npm run start
```
